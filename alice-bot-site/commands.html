Commands

Everything A.L.I.C.E can do, grouped by module. Jump to a section below, or just scroll through — every command shown here is a Discord slash command unless noted otherwise.

📈 Stat Bot

Tracks messages and voice activity for every member and reports back rankings and activity over the last 1, 7, and 14 days.

/ping

Check if the bot is alive and see its current latency.

/stats [user]

Show message and voice activity (1d / 7d / 14d) plus server-wide rank for yourself or another member.

/statleaderboard [count]

Show the server's top members by messages and voice activity (10 per category by default).

🏆 Achievements

Tracks activity across the whole bot — messages, voice time, economy habits, counting streaks, gambling, and pets — and unlocks milestones as you go, each with a coin and XP reward. Separate from the RPG game's own quest achievements below (that's why this command is named /milestones and not /achievements — Discord doesn't allow two commands with the same name).

/milestones [user]

Browse your (or another member's) unlocked and still-locked achievements, by category.

/rank [user]

View your (or another member's) achievement XP rank card.

🛡 Moderation

Automatic message filtering plus an anonymous warning system — three warnings within 24 hours automatically jails the member for 3 hours. Automod deletes the message and issues a warning on its own for blocked words, Discord invite links, emoji spam, excessive caps, repeated messages, and rapid short-message spam — no command needed. Channels can be exempted from the spam checks (slurs and invites still apply everywhere) via /setup spam-exempt.

/warn <user> <reason> [message_id] Mods only

Anonymously warn a user. Optionally reference a message in the current channel to delete it along with the warning.

Warn Message Mods only Right-click a message

Context-menu action — warn a message's author directly, with the message auto-filled and deleted, same as /warn.

/warns [user]

Check how many warnings (out of 3) a user has and when they reset.

/clearwarns <user> Mods only

Clear all warnings for a user.

⭐ Starboard

Messages that get enough ⭐ reactions are automatically reposted into a dedicated starboard channel, and the post keeps updating live as more stars come in. Configured entirely through /setup starboard — see Server Setup below.

⚙️ Server Setup

One command to configure everything else on this list — moderation channels, the jailed role, the starboard, the counting channel, automod exemptions, and the Interactions pack. Every subcommand requires Administrator permission.

/setup channels [mod_warn] [hall_of_shame] [general] [logs] Admin

Set the channels used for /warn, full warn details, light warn notices, and numbered mod-log cases (warn/jail/unjail/timeout).

/setup role <jailed> Admin

Set the role applied automatically on a member's 3rd warning.

/setup starboard [channel] [threshold] Admin

Set the starboard channel and/or how many ⭐ reactions are needed (default 3).

/setup counting <channel> Admin

Set the channel the counting game runs in — required before /count, /buysave, or /saves do anything.

/setup spam-exempt <add|remove> <channel> Admin

Exempt a channel from automod's spam checks (slur and invite detection still apply).

/setup interactions <mature_commands> <command_gifs> Admin

Turn on the Interactions pack (see below) for this server, choosing whether to also allow 18+ commands and whether replies attach GIFs.

/setup view Admin

View this server's current configuration.

🎁 Giveaway

Timed giveaways with weighted entries — messages sent, voice time, and daily-challenge completions can each earn tickets (all three on by default, independently toggleable per giveaway). Members enter by typing !giveaway in the giveaway channel while one is active — not a slash command. The channel becomes entry-only while a giveaway is running; non-mod messages posted there are automatically deleted.

/giveaway start <channel> <duration> <winners> <prize> [track_messages] [messages_per_entry] [track_voice] [hours_per_entry] [track_dailies] Admin

Start a new giveaway — set how long it runs (e.g. 3d, 12h30m), how many winners, and the prize. Optionally toggle which activity earns entries and adjust how much of it earns one ticket.

/giveaway end Admin

Force-end the active giveaway immediately and draw winners.

/giveaway reroll <user> Admin

Reroll a specific winner from the giveaway that just ended — for example, if they didn't claim their prize in time.

/giveaway config <action> [channel] Admin

Add, remove, or view the channels excluded from message-count tracking (e.g. bot-command channels).

/giveaway status

View the active giveaway's details and your own current entry count.

/giveaway entries [user] Admin

See ticket totals and the message/voice/daily breakdown for every entrant, or for one specific member.

🔢 Counting

A community counting game in a designated channel (set via /setup counting) — count up one number at a time, one member at a time. Post the wrong number, or count twice in a row, and the count resets to 1 — unless a save covers the mistake.

/count

Check the server's current count, what's next, and the highest count ever reached.

/buysave

Buy a save for 1,000 coins — automatically forgives your next wrong-number or counted-twice mistake without resetting the count.

/saves [user]

Check your (or another member's) counting save balance.

💰 Economy

A wallet-and-bank currency system with daily rewards, a full grind loop, a shop, heists, and a few ways to gamble it all away. Tip: most commands below also work as a ?-prefix shortcut (e.g. ?bal, ?daily, ?slots 50) — run /econhelp in Discord for the full alias list. The Pets and Roses & Challenges commands below, plus /toolbench, /dailyshop, and /buydaily, are slash-only.

Currency & Banking

/balance [user]

Check wallet and bank balance. Bank balances over 100 coins earn 1% interest daily (1.5% with the Vault Upgrade).

/leaderboard

See the richest members in the server (wallet + bank combined).

/deposit <amount|all>

Move coins from your wallet into your bank.

/withdraw <amount|all>

Move coins from your bank into your wallet.

/transfer <user> <amount>

Send coins from your wallet to another member.

Grinding

/daily

Claim 500 coins, plus a streak bonus (+5% per consecutive day, capped at +100%). Resets every 24 hours, with a 48-hour grace period to keep your streak alive.

/work

Work a shift for a quick, reliable payout.

/apply <job>

Apply for a job — purely cosmetic, flavors the results of your /work.

/beg

Beg for spare change — low risk, low reward.

/crime

Commit a crime for quick cash — riskier than /daily, but a bigger payout if it succeeds. Failing costs a fine.

/dig

Dig through the dumpster for whatever you can find.

/search

Search around for spare coins — safer than /beg, but a smaller reward.

/fish

Cast your line and see what you catch — requires a Fishing Rod from /shop.

/hunt

Head into the woods and see what you bag — requires a Rifle from /shop. Can come back empty-handed.

/sell [item] [quantity|all]

Sell fish or hunted animals from your inventory for coins — omit the item to open an interactive sell menu.

/fishdex

View every fish species, its rarity, catch odds, and sell price.

/huntdex

View every huntable animal, its rarity, catch odds, and sell price.

Gambling

/coinflip <heads|tails> <amount|all>

Bet on a coin flip — double or nothing.

/slots <amount|all>

Spin a 3-reel slot machine. Two matching symbols pay a small multiplier, three of a kind hits the jackpot.

/blackjack <amount|all>

Play blackjack against the dealer using Hit / Stand / Double Down buttons.

Heist & Protection

/bankrob <user>

Attempt to rob a user's bank — works solo, but others can click "Join Heist" within 30 seconds to improve the odds. Failing costs everyone involved a fine.

/rob <user>

Attempt to steal coins straight from another member's wallet — instant and solo, riskier than /crime. Failing costs a fine.

/passive

Toggle Passive Mode — protects you from being robbed, but restricts your own robbing and lowers grind earnings while it's active.

Shop & Items

/shop [category]

Browse items available to buy — Tools, Consumables, or permanent Upgrades.

/buy <item> [quantity]

Buy an item from the shop (quantity is ignored for one-time upgrades).

/inventory

See your tools, consumables, collectables, and upgrades.

/use <item> [quantity]

Use one or more of a consumable (Coffee, Lucky Charm, Disguise, etc.) for a boost on your next matching command — specify a number or "all" (defaults to 1).

/dailyshop

View today's rotating shop selection — a second, separately-stocked shop from /shop that refreshes daily.

/buydaily <item> [quantity]

Buy an item from today's rotating shop.

/toolbench

Purchase, enhance, and upgrade your Fishing Rod and Rifle through an interactive button menu.

Pets

/petshop

View the current pet shop rotation (refreshes every few minutes) — 5 slots, one of which can roll a rarer "wildcard" tier.

/buypet <slot>

Buy the pet sitting in a given /petshop slot (1-5).

/petdex

Browse every pet tier and species — spawn odds, price range, and coin-earn rate.

/pets view [user]

List every pet you (or another member) own, both on display and in storage.

/pets sell <pet>

Sell an owned pet for coins, by its number from /pets view.

/pets feed <pet>

Feed a Pet Treat to a fatigued pet to restore it — pets stop earning once fully fatigued.

/display view [user]

View your (or another member's) display slots and how much coin production is waiting to be collected.

/display place <pet> <slot>

Place an owned pet into a display slot so it starts earning coins passively.

/display remove <slot>

Remove the pet in a display slot and send it back to storage.

/display collect

Collect your pet display's accrued coin production.

/petmenu

A single button-and-menu hub for buying, viewing, placing, feeding, and selling pets — no typing required.

Roses & Challenges

/challenges

View today's daily challenges (send messages, count correctly, gamble, shop, and more) — complete enough of them and you earn a 🌹 rose.

/gift-rose <user> <amount>

Gift roses you've earned to another member. Gifted roses can't be re-gifted, so they can't be passed around indefinitely.

/econhelp

Show every economy command, grouped by category, along with its prefix-command aliases.

⚔️ RPG Game

A text-based adventure — explore, fight monsters, complete quests, gear up (including a blacksmith's forge for crafting weapons and armor from mined ore), and chase achievements across multiple unlockable areas.

/start

Create your character and begin the adventure.

/rpgstats

View your level, XP, gold, HP, attack, and equipped title.

/achievements

Browse your unlocked (and still-locked) RPG quest achievements — a separate system from the server-wide /milestones (see Achievements above).

/rpglb

Show this server's RPG leaderboard.

/rpginventory

Browse your inventory by category — weapons, armor, consumables, tools, materials, items, and titles.

/quests

View available quests and accept or claim them.

/rpguse <item> [quantity]

Use a consumable item from your inventory.

/rpgsell <item> [amount]

Sell an item from your inventory for gold.

/equip <item>

Equip a weapon or armor piece.

/unequip <slot>

Unequip whatever is currently in a gear slot.

/travel <destination>

Freely travel between areas you've already discovered (unlocked after defeating the Bear King).

/progress

Move on to the next area, once you meet its level and item requirements.

/resume

Resend your last fight, gold find, or exploration result if you lost track of it.

/reset

Permanently delete your character so you can /start over.

Admin Commands

/give <user> <item> [amount] Admin

Give an item directly to a player.

/givetitle <user> <title> Admin

Give a title directly to a player.

/setlevel <user> <level> Admin

Set a player's level directly.

/fightmonster <monster> [user] Admin

Start a fight against a specific monster, for yourself or another member.

🎉 Interactions

A pack of lighthearted social action commands — /hug, /kiss, /dance, and about 20 more. Each one posts a themed message about you (and, for the targeted ones, whoever you aim it at), optionally with an attached GIF. Off by default — none of these exist as slash commands in a server until an admin runs /setup interactions (see Server Setup above), which also chooses whether to allow 18+ commands and whether replies attach GIFs.

Aimed at someone

Each takes a required user option — who it's aimed at.

/greet /highfive /dap /handshake /poke /handhold /laughwith /laughat /nuzzle /smile /hug /kiss /slap /punch /kick /bite /lick /cuddle /pat /tickle

Solo

/dance and /pout take an optional user; the rest take none at all.

/dance [user] /pout [user] /laugh /cry /sing /sleep

🎭 Emoji Tools

Quickly bring a custom emoji from another server into this one.

/steal <emoji> [name] Manage Expressions

Steal a custom emoji into this server, optionally giving it a new name.

🗂️ Chat Export

Pulls a channel's full message history out as a JSON file. Gated to Administrator rather than just Moderate Members, since it can expose a lot of message content at once.

/export-chat-history [channel] Admin

Export a channel's full message history as a JSON file (defaults to the current channel).
